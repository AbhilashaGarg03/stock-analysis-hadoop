# Contributing to Stock Analysis Using Hadoop

Thank you for your interest in contributing to this big data project!

## How to Contribute

### Reporting Issues
- Clearly describe any issues
- Include HDFS/Hive logs if relevant
- Specify Hadoop cluster configuration

### Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Test with sample data on Hadoop cluster
4. Make your improvements
5. Document any configuration changes
6. Push and submit a Pull Request

## Code Guidelines

- Document MapReduce logic clearly
- Include Hive query optimization notes
- Provide performance metrics
- Add infrastructure details

## Areas for Contribution

- New analysis queries
- Performance optimization
- Better data visualization
- Documentation improvements
- Hadoop best practices
- Scalability improvements

## Pull Request Process

1. Test on Hadoop cluster
2. Verify HDFS operations
3. Include query results
4. Document infrastructure setup

Thank you for contributing! 🙏
